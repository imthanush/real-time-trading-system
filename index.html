    Trading signal rules

    Deterministic SMA rule. Tolerance is a percentage of SMA, not a dollar amount.

    Decision rule

    BUY: Price > SMA × (1 + tolerance)
    SELL: Price < SMA × (1 − tolerance)
    HOLD: |Price − SMA| / SMA ≤ tolerance, or SMA unavailable

    BUY → T (taken) · SELL/HOLD → N (not taken)

    Indicators

    ΔP[i] = P[i] − P[i−1]
    %Δ[i] = (P[i] − P[i−1]) / P[i−1] × 100
    SMA[i] = mean of P[i−W+1 … i] (null if i < W−1)

    1-bit dynamic branch prediction

    Last-outcome predictor with an explicit warm-up observation.

    How the algorithm works

    1. The first actual branch outcome (T or N) warms up the predictor. It is not a hit or miss.
    2. Each later outcome is predicted as the previous actual outcome.
    3. The prediction is compared with the current actual outcome.
    4. Every evaluated step increments exactly one of hit or miss.
    5. Accuracy = hits / evaluated predictions. If none are evaluated, accuracy is N/A — never 0% or 100% by default.

    CPI derivations

    Reference CPI uses assumed accuracy. Measured CPI uses simulated mispredictions.

    No-prediction baseline

    CPI = 1.0 + (0.25 × 1.00 × 3) = 1.750
    Cycles = 1,000 × 1.750 = 1,750

    90% reference predictor

    CPI = 1.0 + (0.25 × 0.10 × 3) = 1.075
    Cycles = 1,000 × 1.075 = 1,075
    Savings = 675 · Reduction = 38.57% · Speedup = 1.628×

    Measured simulation

    CPI = 1 + (misses × 3) / 1,000
    Example: 5 misses → CPI = 1.015 → 1,015 cycles
    This is not the 90% reference formula.

    What is not claimed

    Modeled cycles are textbook arithmetic. The millisecond figure is JavaScript wall-clock time in this browser. Neither is physical CPU telemetry or exchange latency.

    Why branches matter in a pipeline

    If a processor stalls until a branch resolves, a 3-cycle penalty can be charged on every branch. Prediction reduces how often that penalty is paid.

    Signals are a proxy sequence only

    BUY/SELL/HOLD are mapped to Taken/Not Taken so students can watch a 1-bit predictor. That mapping is pedagogical, not a claim about real trading CPUs.
